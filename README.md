# SkitchUP

محاكي نمذجة ثلاثية الأبعاد يعمل كتطبيق ويب ثابت باستخدام HTML وCSS وJavaScript وThree.js.

## تشغيل المشروع

1. افتح `index.html` عبر خادم ويب محلي أو استضافة صفحات ثابتة.
2. يحتاج التطبيق إلى اتصال بالإنترنت لتحميل Three.js من CDN.
3. لا توجد حالياً خطوة بناء أو تثبيت حزم.

## بنية الملفات

```text
SkitchUP/
├── index.html
├── css/
│   └── main.css
└── js/
    ├── core/
    │   └── engine.js             # إعداد Three.js والمشهد والكاميرا والإضاءة
    └── modules/
        ├── ui.js                 # عناصر الواجهة والأدوات العامة
        ├── library.js            # إنشاء عناصر المكتبة الهندسية
        ├── structural-tools.js   # الأبعاد وحسابات الجمالون والتسميات
        ├── bridge.js             # إنشاء نماذج الجسور
        ├── selection-house.js    # التحديد وأدوات المنزل
        ├── stairs.js             # إنشاء السلالم وحساب أبعادها
        ├── project-tools.js      # الحفظ والفتح وأدوات المشروع
        └── interaction.js        # أحداث اللمس والرسم والتحريك
```

## ملاحظات معمارية

- ترتيب التحميل في `index.html` مقصود: Three.js، ثم محرك العرض، ثم وحدات التطبيق بالترتيب الظاهر في الملف.
- الوحدات حالياً ملفات JavaScript تقليدية (classic scripts)، وليست ES modules. يحافظ ذلك مؤقتاً على نطاق المتغيرات والدوال المشتركة في التطبيق الأصلي.
- لا تنقل أو تعِد ترتيب تعريفات الوحدات دون مراجعة الاعتماديات بينها؛ بعض الوحدات تستخدم متغيرات ودوال عُرّفت في وحدات سابقة أو لاحقة.
- هذا الفصل تنظيمي أولي، وليس عزلاً كاملاً للاعتماديات. يمكن في مرحلة لاحقة تحويل الوحدات إلى ES modules بعد تحديد واجهات واضحة بينها.

## اختبار يدوي بعد أي تعديل

- تحميل الصفحة دون أخطاء في وحدة تحكم المتصفح.
- ظهور المشهد والشبكة والإضاءة.
- تدوير الكاميرا وتحريكها والتكبير بإيماءات اللمس.
- إنشاء مجسم وتحديده وتحريكه وتغيير أبعاده.
- تجربة التراجع والحفظ والفتح.
- تجربة أدوات المنزل والسلالم والجسر والجمالون.
