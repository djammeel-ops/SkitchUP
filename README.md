# SkitchUP

محاكي نمذجة ثلاثية الأبعاد يعمل كتطبيق ويب ثابت باستخدام HTML وCSS وJavaScript وThree.js.

## تشغيل المشروع

1. افتح `index.html` عبر خادم ويب محلي أو استضافة صفحات ثابتة.
2. يحتاج التطبيق إلى اتصال بالإنترنت لتحميل Three.js من CDN.
3. لا توجد حالياً خطوة بناء أو تثبيت حزم.

## بنية الملفات

```text
SkitchUP/
├── index.html
├── css/
│   └── main.css
└── js/
    ├── core/
    │   └── engine.js
    └── modules/
        ├── layers.js              # الطبقات: الإنشاء، التفعيل، الإظهار والقفل
        ├── ui.js                  # عناصر الواجهة والأدوات العامة
        ├── library.js             # عناصر المكتبة الهندسية
        ├── structural-tools.js    # الأبعاد وحسابات الجمالون والتسميات
        ├── bridge.js              # إنشاء نماذج الجسور
        ├── selection-house.js     # التحديد وأدوات المنزل
        ├── stairs.js              # إنشاء السلالم وحساب أبعادها
        ├── project-tools.js       # الحفظ والفتح وأدوات المشروع
        └── interaction.js         # أحداث اللمس والرسم والتحريك
```

## الطبقات

- كل مجسم جديد يُضاف إلى الطبقة النشطة.
- يمكن إنشاء طبقة، تفعيلها، إعادة تسميتها أو حذفها.
- إخفاء الطبقة يخفي مجسماتها من المشهد ومن عمليات الالتقاط والتحديد.
- قفل الطبقة يمنع تحديد مجسماتها وتعديلها.
- عند حذف طبقة، تُنقل مجسماتها إلى طبقة أخرى بدلاً من حذفها.
- حفظ المشروع يخزن أسماء الطبقات وحالتها والطبقة المخصصة لكل مجسم.
- فتح المشاريع القديمة ذات تنسيق الحفظ السابق يضع محتوياتها في «الطبقة 1».

## ملاحظات معمارية

- ترتيب التحميل في `index.html` مقصود: Three.js، ثم محرك العرض، ثم مدير الطبقات، ثم وحدات التطبيق.
- الوحدات ملفات JavaScript تقليدية (classic scripts) وليست ES modules للمحافظة مؤقتاً على نطاق المتغيرات والدوال المشتركة.
- هذا الفصل تنظيمي أولي؛ تحويل الملفات إلى ES modules يتطلب تحديد واجهات الاعتماديات بينها.

## اختبار يدوي

- تحميل الصفحة دون أخطاء في وحدة تحكم المتصفح.
- إنشاء طبقتين ونقل العمل الجديد بينهما.
- إخفاء طبقة والتأكد من اختفاء مجسماتها وعدم التقاطها.
- قفل طبقة والتأكد من تعذر تحديد مجسماتها.
- إعادة إظهار الطبقة وفتح قفلها.
- حفظ المشروع ثم فتحه والتأكد من بقاء الطبقات وتوزيع المجسمات.
- تجربة التراجع والحذف والنسخ وأدوات المنزل والسلالم والجسر والجمالون.
