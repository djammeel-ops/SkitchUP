# SkitchUP

محاكي نمذجة ثلاثية الأبعاد يعمل كتطبيق ويب ثابت باستخدام HTML وCSS وJavaScript وThree.js.

## تشغيل المشروع

1. افتح `index.html` عبر خادم ويب محلي أو استضافة صفحات ثابتة.
2. يحتاج التطبيق إلى اتصال بالإنترنت لتحميل Three.js من CDN.
3. لا توجد حالياً خطوة بناء أو تثبيت حزم.

## بنية الملفات

```text
SkitchUP/
├── index.html              # هيكل الواجهة ونقاط تحميل الملفات
├── css/
│   └── main.css            # جميع الأنماط
└── js/
    ├── core/
    │   └── engine.js       # إعداد Three.js: المشهد والكاميرا والعرض والإضاءة
    └── app.js              # أدوات الرسم والنمذجة والتفاعل والحفظ
```

## ملاحظات معمارية

- يتم تحميل Three.js أولاً، ثم `js/core/engine.js`، ثم `js/app.js`.
- ملفات JavaScript تستخدم حالياً classic scripts وليست ES modules. هذا مقصود في مرحلة الفصل الأولى للمحافظة على نطاق المتغيرات المشتركة وسلوك التطبيق الحالي.
- لا تغيّر ترتيب تحميل ملفات JavaScript قبل فصل الاعتماديات المشتركة صراحةً.
- المرحلة التالية هي تقسيم `app.js` تدريجياً إلى وحدات مستقلة (الكاميرا، أدوات الرسم، التحديد، النمذجة، الحفظ والواجهة)، مع اختبار التطبيق بعد كل نقل.

## اختبار يدوي بعد أي تعديل

- تحميل الصفحة دون أخطاء في وحدة تحكم المتصفح.
- ظهور المشهد والشبكة والإضاءة.
- تدوير الكاميرا وتحريكها والتكبير بإيماءات اللمس.
- إنشاء مجسم وتحديده وتحريكه وتغيير أبعاده.
- تجربة التراجع والحفظ والفتح.
- تجربة أدوات المنزل والسلالم والجسر والجمالون.
